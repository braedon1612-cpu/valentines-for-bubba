# Valentines for Bubba

A small, self-contained Valentine's Day greeting built with HTML, CSS and vanilla JavaScript.

## Features

- Pink gradient background and personal greeting.
- A button reveals an extra message with a two-second fade transition.

## Run locally

Clone the repository:

```sh
git clone https://github.com/braedon1612-cpu/valentines-for-bubba.git
cd valentines-for-bubba
```

Open `./index.html` in a modern browser. No package installation or build step is required. HTML, CSS and JavaScript run in the browser.

## Project structure

- `index.html` — greeting, embedded styles and `showMessage()` interaction.

## Customization and checks

Edit the page text and styles in the HTML file. Keep referenced asset filenames and capitalization consistent. After changes, reload the page and check its layout on desktop and mobile, then exercise each interactive control. No automated test suite is included.
